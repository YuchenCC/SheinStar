# Latina_Glam_Sunny_Ecom_05

## 用途

用于 Shein、跨境电商、快时尚商品图、明艳女装穿搭图、修身款展示、详情页模特图。适合搭配修身上衣、裙装、套装、牛仔裤、派对休闲风商品出镜。

## 固定特征

- 模特身份：成年拉美女性电商服装模特
- 年龄感：22-28 岁
- 肤色：暖橄榄小麦色
- 发色：蜂蜜棕
- 发型：长发柔顺大波浪，精致但自然
- 脸型：精致鹅蛋脸
- 眼睛：明亮棕色眼睛
- 眉毛：柔和自然眉
- 鼻梁：挺直精致鼻梁
- 嘴唇：自然饱满唇形
- 妆容：清透明艳妆，干净底妆，柔和高光，自然玫瑰唇色
- 身材：明艳修长曲线身材，接近黄金比例，腿长腰细，胸部偏大但比例自然，用于突出服装上身 3D 立体感
- 气质：阳光、精致、明艳、亲和、快时尚感
